Project Information
===================

Dependencies
------------

To maintain a minimal footprint, the client relies on only two core libraries:

- **httpx**: A fully featured, lightweight HTTP client.
- **click**: A composable command-line interface framework.

License
-------

``bib-ami`` is released under the **MIT License**. This permissive license ensures the client can be freely integrated into academic tools, open-source RAG frameworks, and proprietary enterprise pipelines without legal friction.
