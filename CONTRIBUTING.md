# Contributing to bib-ami-client

Thank you for your interest in `bib-ami-client`!

`bib-ami-client` is developed, maintained, and supported directly by **Carlson Research, LLC**. To ensure a focused development path and maintain strict quality standards across both our open-source client tools and commercial cloud integrations, **we are not accepting external code Pull Requests (PRs) at this time.**

However, feedback, bug reports, and feature requests from the research community are always welcome and greatly appreciated!

---

## How You Can Help

### 1. Reporting Bugs
If you encounter a bug, CLI error, or network connection issue while using `bib-ami-client`, please open an issue on our GitHub repository.

To help us resolve the issue quickly, please include:
* **A clear, descriptive title.**
* **Steps to reproduce the issue** (including specific CLI arguments or code snippets).
* **Expected vs. actual behavior** (along with error outputs or stack traces).
* **Environment details:** Operating system, Python version, and `bib-ami-client` version (`bib-ami --version`).

### 2. Feature Requests & Feedback
Have an idea for a new CLI command, configuration flag, or workflow improvement? Please open a GitHub Issue tagged as a **Feature Request**. We review all community feedback when planning future updates for `bib-ami-client` and our backend services.

---

## Pull Requests & Code Contributions

Please note that unsolicited Pull Requests will be closed without review. We ask that developers refrain from submitting code contributions so that we can focus our engineering efforts on core client stability, security, and backend cloud integrations.

---

## Need Enterprise Scale or High Throughput?

If your organization requires high-throughput citation verification, custom API integrations, or dedicated SLAs, please check out the hosted **bib-ami Cloud Service** available on AWS Marketplace and Google Cloud Marketplace, or contact **Carlson Research, LLC**.

Thank you for using `bib-ami-client` and helping us keep academic literature verified and accessible!
